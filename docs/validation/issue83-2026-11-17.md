## Failure and fix

The unreleased driver supplies physical Arrow `decimal256(76,16)` alongside
bare `NUMERIC` metadata for the empty duration query used in unit-test schema
inference. The Redis column builder previously preferred the bare label;
subsequent parsing defaulted it to `decimal(38,0)`, rounding the expected
fixture value `30.5` to `31`. Both baseline and the runner refactor reproduced
this failure; the driver itself returned the correct `30.50` duration.

For physical Decimal128/Decimal256 fields, Redis now renders Arrow precision
and scale when the metadata label is bare NUMERIC or DECIMAL. Parameterized
SQL declarations remain authoritative. No fixture values or tests were removed.
The new regression failed before the fix and passes afterward, covering
fractional/zero scales, precision 76, case/whitespace and explicit declarations.
The live compiled fixture now uses `CAST(30.5 AS decimal(76, 16))`.
