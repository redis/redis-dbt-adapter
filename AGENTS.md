# Redis driver versions

Use the latest stable Redis ADBC driver release for development and validation.
Check the release in `redis/redis-adbc-driver` before starting driver-dependent
work, and keep `v1/scripts/driver-version`, `v2/upstream.json`, and current setup
documentation aligned with that policy (`latest` where the resolver is supported). Keep historical validation versions accurate;
record the actual driver revision used for new results.
